# Windows 激活工具 (Windows Activator)

Windows 激活工具是一款现代化的 Windows 数字权利激活模拟与版本无缝转换工具箱。

![UI界面截图][UI_image]

## 主要特性

- **数字权利 (HWID)**：支持 Windows 10 与 Windows 11 永久数字权利授权。
- **KMS38 离线票据**：支持离线 KMS 票据绑定，授权有效期长达 2038 年。
- **KMS / GVLK**：大客户批量激活渠道，覆盖 Enterprise、Education 及 LTSC 全系列。
- **OEM SLIC 2.1**：传统 BIOS 证书与 OEM:SLP 令牌仿真（支持 Windows 7 / Server 2008）。
- **Hyper-V AVMA**：虚拟机自动激活绑定机制。
- **热补丁免重启更新**：支持启用与配置 Windows 热补丁（Hotpatch）权益。
- **主题工坊 (Theme Studio)**：内置 1,500 套精心微调主题，覆盖 26 个精选合集与动态 Mica 效果。
- **全球多语言支持**：涵盖 48+ 国际语言，支持一键即时热切换。

## 命令行启动参数

本程序支持通过命令行参数运行：

```
-a  --auto            启动后自动执行激活。
-e  --expact          自动激活时允许使用实验性方案。
-h  --hide            静默模式运行。
-l  --log             输出诊断日志到文件。
-?  --help            显示帮助对话框。
```
